# 🌿 Greenden – Plant Store Website

## 📌 About the Project

Greenden is a simple and responsive plant store website developed using **HTML and Tailwind CSS**. The website is designed to showcase a variety of plants and provide users with a clean, attractive, and user-friendly browsing experience.

This mini project helped me practice HTML structure, Tailwind CSS utility classes, responsive web design, and navigation between multiple web pages.

## ✨ Features

- 🏠 **Home Page** – An attractive landing page introducing the Greenden plant store.
- 🌱 **Products Page** – Displays a collection of plants with images and product details.
- 📩 **Contact Page** – Provides a section for users to get in touch.
- 📱 **Responsive Navigation Bar** – Navigation links for easy movement between pages.
- 🎨 **Tailwind CSS Styling** – Uses utility classes to create a clean and modern design.
- 🖼️ **Plant Images** – Displays plant images to enhance the website's appearance.

## 🛠️ Technologies Used

- **HTML5** – For structuring the web pages.
- **Tailwind CSS** – For styling and responsive layouts.
- **JavaScript / Node.js** – Used only if applicable to your project setup.
